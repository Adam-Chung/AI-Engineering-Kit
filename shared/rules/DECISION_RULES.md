# Technical Decision Rules

Use these rules when two or more viable approaches could materially affect the outcome.

Identify the decision criteria and relevant constraints before comparing solutions.

Compare only the factors relevant to the decision, such as:

- Suitability for the requirements
- Advantages and disadvantages
- Implementation complexity
- Maintainability
- Scalability
- Performance
- Security
- Cost
- Learning value

State important assumptions and uncertainties.

Recommend the most practical solution for the current context.

Explain the decisive trade-offs and when an alternative would be more appropriate.

Do not create artificial alternatives or lengthy comparisons for trivial decisions.
